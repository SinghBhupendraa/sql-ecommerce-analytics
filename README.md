# SQL Ecommerce Analytics

## Project Objective
Perform exploratory data analysis (EDA), business KPI reporting, and advanced SQL analytics on ecommerce transactional datasets.

## Dataset
Brazilian Ecommerce Public Dataset by Olist

## Tools Used
- SQL
- PostgreSQL / MySQL
- GitHub

## Topics Covered
- Data Profiling
- Data Cleaning
- Joins
- Aggregations
- Window Functions
- Common Table Expressions (CTEs)
- Business KPI Analysis
- Customer Analytics
- Revenue Analysis

## Project Workflow
1. Understand relational schema
2. Perform data profiling
3. Clean inconsistent records
4. Write analytical SQL queries
5. Build KPI-based business insights
